# AI Career Copilot

AI-powered resume analyzer built with Flask, Groq LLM, SQLAlchemy, and MySQL.

## Features

- User Authentication
- Resume Upload
- AI Resume Analysis
- Skill Gap Detection
- Learning Roadmaps
- Interview Questions

## Tech Stack

- Python
- Flask
- SQLAlchemy
- MySQL (TiDB)
- Groq API
- HTML/CSS
